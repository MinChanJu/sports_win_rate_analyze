# React + TypeScript + Vite
이 프로젝트는 스포츠 경기 승률 분석을 위한 웹 애플리케이션입니다. React, TypeScript, Vite를 사용하여 개발되었습니다.

## 과정
```bash
npm create vite@latest web
◇  Select a framework:
│  React
│
◇  Select a variant:
│  TypeScript + SWC
│
◇  Use rolldown-vite (Experimental)?:
│  No
│
◇  Install with npm and start now?
│  No
```

```bash
cd web
npm install
npm run dev
```
